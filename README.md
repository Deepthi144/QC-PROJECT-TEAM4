# 🔐 Quantum-Based Image Encryption and Secure Decryption System

## 📌 About the Project

The **Quantum-Based Image Encryption and Secure Decryption System** is a web-based application that provides secure image protection using quantum-based random key generation and AES-256-GCM encryption.

The system uses **Qiskit Aer** to generate quantum-based random bits and creates a 256-bit encryption key. The uploaded image is encrypted using AES-256-GCM, while SHA-256 is used for integrity verification. Users can encrypt, download, and securely decrypt their images using the correct key.

## ✨ Features

- Quantum-based 256-bit key generation
- AES-256-GCM image encryption
- Secure image decryption
- SHA-256 integrity verification
- Encrypted pixel visualization
- Download encrypted and decrypted files
- Simple web-based interface

## 🛠️ Technologies

**Frontend:** React.js, Vite  
**Backend:** Python, Flask  
**Quantum:** Qiskit, Qiskit Aer  
**Encryption:** AES-256-GCM  
**Integrity:** SHA-256  
**Deployment:** Render
